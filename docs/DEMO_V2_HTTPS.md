# Demo v2：H200内网HTTPS共享操作台

同事直接访问H200内网IP，使用浏览器麦克风；共用热词与历史、轮流录音。
默认只加载麦克风，不再自动筛选案例。模型、发音、检索门控和解码参数不变。
自由麦不设总录音时长上限，由用户点击“结束并定稿”。
右侧词表取自当前有效检索索引，词面去重；包含基础词与临时覆盖/新增词。
搜索支持包含匹配和完全存在提示，列表支持滚动、拖动底边调整高度。
空闲页面每5秒同步共享状态；有人录音时禁用其他页面修改和启动操作，服务端也做互斥。

## 1. 容器内启动

在原环境中，先结束同一张卡上旧Demo进程，再运行：

```bash
cd /host_home/star/q00933266/qwen3-asr-hotword
git pull --ff-only origin codex/g2p-coverage-scan
bash scripts/start_zh_rag_demo_https.sh --gpu 5 --port 8444
```

`--gpu`是物理卡号，不传为3；原有55GiB空闲检查保留。
默认地址10.44.168.92、端口8444，避开同事示例中的8443；若8443空闲可把端口改成8443。
首次生成证书需要已有openssl（支持`req -addext`，工区Ubuntu版本支持）。不安装其他包。
需要公司已有证书时在同一命令后添加`--tls-cert /证书路径 --tls-key /私钥路径`，
证书必须覆盖访问IP，或通过`--public-host 公司域名`使用证书覆盖的域名。
自动生成证书仅支持IP地址。

等待打印“内网访问”。终端需持续运行。原普通HTTP入口也默认仅麦克风；
如确实需要恢复实测案例，可明确追加`--max-cases 150`，进入时仍选自由麦克风。

## 2. 宿主机接入现有容器（另开一个终端，容器外）

```bash
cd /home/star/q00933266/qwen3-asr-hotword
python3 scripts/expose_zh_rag_demo.py
```

该命令读取共享目录`outputs/demo_https_endpoint.json`，自动找到刚启动的容器和端口，
通过Docker inspect读取容器IP，将10.44.168.92的该端口透传到容器HTTPS服务。
不解密TLS、不修改Docker配置、不重建容器、不改原挂载；只需宿主机Python3和Docker查询权限。
若账号没有Docker权限，用有权限账号运行。此终端也保持运行，Ctrl+C关闭转发。
host网络容器无需转发，脚本会提示。已有同端口映射时也无需再开代理。
端口被别的服务占用会报错，不会结束或替换别人的服务。

多容器/自定义hostname时可手动指定：

```bash
python3 scripts/expose_zh_rag_demo.py --container 实际容器ID --host-ip 10.44.168.92 --port 8444
```

容器有多个网络时追加`--container-ip`选择inspect中实际存在的地址。
每次重建/更换容器，先启动Demo，再重启转发；不把旧容器地址永久写入系统。
服务器网络需要允许同事到10.44.168.92所选TCP端口；仅SSH可达不代表网页端口可达。

## 3. 直接访问，无需访问口令

打开 `https://10.44.168.92:8444/` 即自动连接共享操作台，不需要登录或输入口令。
用户选择先使用浏览器“高级→继续访问”，若可授权麦克风并正常录音，可省略电脑导入证书。
若浏览器仍阻止麦克风，再使用下方信任证书方式；代码不强制要求导入CA。

自动证书模式会生成公开CA文件：

```text
容器内 /host_home/star/q00933266/qwen3-asr-hotword/outputs/demo_ca.crt
宿主机 /home/star/q00933266/qwen3-asr-hotword/outputs/demo_ca.crt
```

需要信任证书时，把这个`.crt`发给同事，在各自电脑导入并信任：

- Windows：双击证书 → 安装证书 → 当前用户 → 放入“受信任的根证书颁发机构”。
- macOS：导入“钥匙串访问”的登录钥匙串，打开该证书，信任中设置“始终信任”。
- 公司设备限制个人导入时，请管理员配置证书，或改用公司已信任的服务证书。

只传公开`.crt`；私钥存放在`outputs/demo_tls/`，不要复制或传递`.key`。
浏览器信任后重新访问 `https://10.44.168.92:8444/`，允许麦克风即可开始录音。
仅点击“不安全仍继续”不作为麦克风可用的保证；HTTPS必须被浏览器识别为安全上下文。
使用已有公司证书且客户端已信任时，不需要导入本项目CA。

## 长录音与手动停止

取消网页30秒自动停止。后台仍按每2秒接收音频，每30秒完成当前识别段并建立下一段，
左右两路采用相同分段，已完成文本累积保留。模型不会收到无限增长的单次输入。
段与段之间重置ASR上下文及CTC音频前缀，热词表不变；跨段词句可能受影响，
此长录音模式不等同于整段无限上下文推理，也不直接作为原流式评测指标。
不足30秒或恰好30秒停止均可；最后不足2秒的音频也会送去定稿。

麦克风原声逐块写到本次目录`recordings/*.s16le`（16kHz、单声道、有符号16位小端PCM），
约110MiB/小时。最近一次成功定稿的录音支持分块重播，验证完整音频SHA256一致，
不把整份长录音加载进浏览器音频缓冲或服务器PCM缓存。
取消/异常产生的部分录音保留在本次目录，但不会替换上一次可重播的录音。
重启不自动恢复旧录音会话；历史目录保留。磁盘、网络和服务仍需正常，
关闭浏览器、电脑休眠或推理报错不保证继续采集；处理落后时点击停止后会先排空队列。

## 产物与核验

每次启动新建`outputs/zh_rag_demo_v2_*/`，历史不删除，也不自动恢复为新会话。
本次`startup.json`记录gpu、https、public_url、case_limit（默认0）和模型身份。
新增词和转写写入同目录`session_history.jsonl`，转写条目记录总秒数、分段数、原声哈希和录音路径。旧实测案例缓存保留。
按用户要求不设访问口令，能访问该内网端口的人共用词表和会话。
录音过程仍使用内部会话ID和序号保持单人操作，浏览器自动处理，无需用户输入。
`outputs/demo_https_endpoint.json`仅记录容器/公开入口。

核验页面右上角卡号、自由麦克风、词表搜索以及两人轮流录音。
持续说话超过60秒，应继续采集；手动停止后检查全文和总秒数，再重播检查原声完整。
需排查时回传本次`startup.json`和启动/转发错误文本，不要传私钥。
本地验证包括真实TLS握手和证书信任、无口令访问、词表、录音互斥、TCP字节透传，
以及浏览器桌面/窄屏布局、存在/不存在搜索、滚动。未在本地运行H200语音推理，
H200端口可达和同事电脑证书信任需部署后确认。
