# 中文音素 RAG 录屏演示 · 第一版

## 在工区启动

在能读取模型、训练输出和评测音频的 **H200 容器**，使用 `qwen3-asr-hotword` Conda 环境：

```bash
cd /host_home/star/q00933266/qwen3-asr-hotword && git pull --ff-only origin codex/g2p-coverage-scan && bash scripts/start_zh_rag_demo.sh
```

默认仅用物理 GPU 5，启动前检查至少 55 GiB 空闲；这是启动门槛而非实测显存。沿用已安装的 `.venv/qwen_asr_vllm023_cu129/bin/python`，无需重装 vLLM。不启动训练。核验模型资产、启动解码引擎、挑选实测样例后终端打印“已就绪”。保持此终端运行。

在**录屏电脑**另开终端，执行服务打印的 `ssh -N -L ...`，把 `star@starpc` 换成你平时登录这台宿主机的 SSH 地址（含必要的端口或跳板配置）。保持隧道打开，然后在电脑 Chrome/Edge 打开服务打印的带 `#` 的完整 localhost 地址。这是私有演示口令，不要录入视频。此方式要求 SSH 宿主机可以访问容器 IP 的服务端口，无需为已在用的容器重新映射端口。若本地 8765 被占用，可启动时附加 `--port 8875`，使用对应的新隧道。麦克风授权发生在录屏电脑，不是服务器。

## 推荐录制顺序

1. 在“音频来源”选已核验的中文例句。此时仅从本场背景索引中取出该例的目标词，其余词仍参与竞争。输入框预填目标便于操作，**没有添加就不会因为预填而传给模型**。
2. 点“播放验证集原声”。听一句、看两路定稿。点“添加热词”，页面显示实际发音；右侧提示区此时还不是识别结果。
3. 再播**同一条原声**：看右下方本步候选、绿色转写命中和两路最终文本。每步最多 7 词，可为空。回改只在模型确实修改早先文字时显示，不做假动画。切换案例会清空临时词并重置该例的背景索引。
4. 也可选“自由麦克风”，输入中文专名后点“添加热词”，再点“开始说话”和“结束并定稿”。浏览器只采集一次，限制 30 秒；两栏收到相同 PCM。麦克风换了说话人或环境，结果可能和验证集原声不同。

## 怎么选出能展示的句子

- 从历史 AISHELL 中文关键词子集和智慧家庭中文正例验证集的原声中取 2–15 秒、目标写在参考里的样本；AISHELL 使用审核过的词面和已排除的句词对。使用既有中英 480 小时版（183 类、epoch 25）的 **11 组流式检索缓存** 过滤曾经通过 Top7 门控的目标。缓存只负责缩小范围。
- 随后拿原声真实解码两遍。未加目标时左右都漏掉；加入目标后，右栏至少有一个音频步检索并注入该词，且最终文字含该词；左栏两次最终文字相同。只把满足这组条件的例句推荐给用户。参考句和期望答案不进入请求。现场播放仍会重新推理。
- 默认最多试 24 个候选、留两个不同的成功目标。0 个时照样可使用麦克风，不伪造例子。可重新启动并附加 `--max-cases 80` 扩大搜索，或 `--max-cases 0` 跳过选例，直接体验麦克风。此为录屏个案筛选，不能据此报告总体收益。

## 模型、边界和产物

- 基座 `/glusterfs_103/models/Qwen3-ASR-1.7B`；检测头 `outputs/zh_en_183_noise70_dual_v2/head/ctc_head_best.pt`。启动核验训练记录、权重身份、183 类顺序及 `configs/zh_en_joint2351.v1.jsonl`。右栏使用中英联合背景词库、同版 Anchor/局部重排/门控参数。中文新增词经训练时的前端与 `mandarin_china_mfa` 3.0.0 Top1 转为 token ID。无法完整映射时不入库；正式文件不变。
- 旧 Conda 环境运行 CTC 检索和官方 Qwen 流式状态机；原生 vLLM 0.23.0 子进程加载一个解码引擎，轮流处理左右两份独立状态，避免第三份模型。这里仍有检索模型与解码模型两份加载。每满 2 秒按当时已收到的音频检索、更新右栏提示并解码；末尾不足 2 秒也定稿。留 5 个 token 可回改，前 2 块不固定前缀。本版没有声称只算一次 Encoder；两栏耗时也不能用于比较后端性能。
- 每次启动使用新 `outputs/zh_rag_demo_*/`，终端会打印确切路径。`startup.json` 存模型身份和选例数量，`case_checks.jsonl` 存已实际尝试的前后结果，`verified_cases.json` 只在确有推荐案例时写入。可返回 `startup.json` 和 `verified_cases.json`；若为 0 返回 `case_checks.jsonl` 以便分析。不会把麦克风原声写入磁盘。
- `Ctrl+C` 退出本次服务；再运行会重新加载并验证样例，不覆盖之前目录，不需要 `--resume`。若未挂载选例音频/历史缓存，可先用 `--max-cases 0`，它不会宣称已验证样例。
